# Textile B2B Marketplace - Frontend

React + Vite based frontend for Textile B2B Marketplace.

## Features

- Mobile OTP Login
- Product Listing with ₹9 Payment
- Real-time Chat between Buyers & Sellers
- Seller Dashboard
- Product Filters & Search
- Responsive Design

## Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
